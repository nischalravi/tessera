# Tessera Provider

Manage Tessera configuration as code. The provider signs in as a machine client (OAuth client credentials with a
private-key JWT, RFC 7523, optionally DPoP-bound) and talks only to the public `/api/v1` API. It never uses a browser
session or the dev IdP. A machine client holds the viewer, operator and auditor roles at most, so the provider can only
manage what those roles may change without a step-up sign-in; see the module README for what that covers.

## Example Usage

```terraform
terraform {
  required_providers {
    tessera = {
      source = "nischalravi/tessera"
    }
  }
}

# Every value can come from the environment instead (TESSERA_ENDPOINT, TESSERA_TENANT, TESSERA_CLIENT_ID,
# TESSERA_PRIVATE_KEY_FILE, TESSERA_KEY_ID, TESSERA_DPOP), which keeps them out of the configuration.
provider "tessera" {
  endpoint         = "https://tessera.example.com"
  tenant           = "larkspur"
  client_id        = "tsc_3bkinseovjluwkan"
  private_key_file = "/etc/terraform/tessera-client-key.pem"
  key_id           = "ci-1"
  dpop             = true # the client was registered with dpop_required
}
```

## Schema

### Optional

- `ca_file` (String) A PEM file of extra trusted CA certificates, for a private PKI. Env: `TESSERA_CA_FILE`.
- `client_id` (String) The machine client's id (`tsc_...`), from Admin > API clients or `tessera admin add-client`. Env: `TESSERA_CLIENT_ID`.
- `dpop` (Boolean) Bind the access token to a per-run DPoP key (RFC 9449). Set it when the client is registered with `dpop_required` (the default for clients made in the UI). Env: `TESSERA_DPOP`.
- `endpoint` (String) The server's public URL, for example `https://tessera.example.com`. Plain http is accepted for localhost only. Env: `TESSERA_ENDPOINT`. It must be the URL the server advertises as its token endpoint's origin (`TESSERA_PUBLIC_URL`).
- `insecure_skip_verify` (Boolean) Skip TLS certificate verification. For throwaway test servers only; verification is on by default.
- `key_id` (String) The `kid` the public key is registered under. Env: `TESSERA_KEY_ID`. Optional when the client has one key.
- `private_key` (String, Sensitive) The client's PEM private key (ES256 P-256 or EdDSA Ed25519); the matching public key is registered with the client. Env: `TESSERA_PRIVATE_KEY`. Prefer `private_key_file` or the env var over a literal in configuration.
- `private_key_file` (String) Path to the PEM private key. Env: `TESSERA_PRIVATE_KEY_FILE`. Exactly one of `private_key` and `private_key_file`.
- `scope` (String) Space-separated scopes to request (`tessera:read`, `tessera:write`, `tessera:audit`). Default: every scope the client holds.
- `poll_interval` (String) How often a waiting resource asks whether the change was approved, as a duration such as `5s` (at least `100ms`). Default `5s`. Env: `TESSERA_POLL_INTERVAL`.
- `tenant` (String) The tenant slug. Env: `TESSERA_TENANT`.
- `wait_timeout` (String) How long a resource that proposes a change (`tessera_alert_rule`, `tessera_catalog_item`, `tessera_business_role`, `tessera_sod_ruleset`) waits for a person to approve it, as a duration such as `30m`. Default `30m`. On a timeout the apply fails with the change's URL; the proposal stays open for 72 hours. Env: `TESSERA_WAIT_TIMEOUT`.
