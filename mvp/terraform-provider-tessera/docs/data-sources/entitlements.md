# tessera_entitlements (Data Source)

The entitlements (groups, roles, permission sets) found in the connected systems. Needs the `tessera:read` scope.

## Example Usage

```terraform
data "tessera_entitlements" "aws_privileged" {
  system = "aws"
}

output "aws_privileged_entitlements" {
  value = [for e in data.tessera_entitlements.aws_privileged.entitlements : e.name if e.privileged]
}
```
