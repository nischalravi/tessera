# tessera_identities (Data Source)

The tenant's identities (people, service accounts, agents). Use an `id` for `escalation_identity_id` of a
`tessera_review_schedule`. Needs the `tessera:read` scope.

## Example Usage

```terraform
data "tessera_identities" "service_accounts" {
  type   = "service_account"
  status = "active"
}

output "service_account_names" {
  value = [for i in data.tessera_identities.service_accounts.identities : i.name]
}
```
