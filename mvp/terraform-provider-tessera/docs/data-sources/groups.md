# tessera_groups (Data Source)

The groups found in the connected systems (read-only; the group folders API is not open to machine clients). Needs the `tessera:read` scope.

## Example Usage

```terraform
data "tessera_groups" "privileged_aws" {
  system     = "aws"
  privileged = true
}

output "privileged_aws_groups" {
  value = [for g in data.tessera_groups.privileged_aws.groups : g.name]
}
```
