# Market watch

The weekly market-watch run writes one report here per week, named `YYYY-MM-DD.md`. Each report covers only what is new since the previous one.

## Report template

```markdown
# Market watch — YYYY-MM-DD

## Summary
Three to five sentences: the most important changes this week and what they mean for Tessera.

## Competitors
| Date | Company | What happened | Why it matters to Tessera | Source |

## Incidents and attack techniques
| Date | Incident | Root cause | IAM control that would have stopped it | Tessera coverage (have / partial / none) | Source |

## Standards and regulation
| Standard | Change | Effective date | Knowledge-base doc updated? | Source |

## What customers are struggling with
For each theme: the problem in the customer's words (paraphrased), how many independent sources, the strongest evidence links, and who has it (company size, role).

## Security advisories affecting our stack
| Package / component | Advisory | Severity | Affects Tessera? | Action |

## Proposed backlog
| Title | Problem and evidence | Capability-map row | Priority | Size | New issue or existing # |

## Knowledge-base changes made
List each edit to `docs/knowledge/` and why.
```

Facts that could not be verified are marked `[unverified]`.
